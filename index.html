Project 5

업무/인사관리 플랫폼 '사무보조(SAMUBOZO)' 신규 개발 (플레이데이터 최종 프로젝트)

주요 역할

  • MSA 환경에서 Spring Cloud Gateway를 활용한 API 라우팅 및 인증/인가 구현
  • 쪽지/알림 서비스 개발: SSE(Server-Sent Events)를 이용한 실시간 알림 기능 구현
  • 일정 관리 서비스 개발: 전사, 팀, 개인 일정을 공유하는 캘린더 기능 구현
  • Jenkins, Docker, Kubernetes(EKS)를 활용한 CI/CD 파이프라인 구축 및 자동 배포 환경 설계
  • AWS(ECR, EKS, S3, Route53)를 이용한 클라우드 인프라 구축 및 운영

기술 스택

Java/Spring Boot Spring Cloud Gateway JPA React.js AWS EKS Kubernetes Docker Jenkins

📌 핵심 성과: MSA 기반 시스템 설계 및 DevOps 역량 확보

커리큘럼에서 배운 스택을 체득하기 위해 MSA(Microservice Architecture) 기반의 시스템을 설계하고 개발했습니다. 각 도메인별 서비스를 독립적으로 구축하고 API Gateway를 통해 통신하는 과정을 주도하며 서비스 분리에 대한 이해를 높였습니다. 특히 Jenkins와 Kubernetes를 사용하여 개발부터 테스트, 배포까지 이어지는 CI/CD 파이프라인을 직접 구축하며, 현대적인 DevOps 개발 문화에 대한 실질적인 경험과 역량을 확보했습니다.
